# Relecture critique de l'app avant publication

## Contexte
Relecture demandée avant README et déploiement : exactitude statistique, cohérence, clarté, points ouverts liés aux textes. Aucun fichier modifié. Sources lues : `app/textes.py`, `app/vues/*.py`, `app/charte.py` (libellés), `docs/app.md`, `docs/method.md`, agrégats de `data/processed/resume_global.json`.

Valeurs utilisées : contraste fort − moyen +0,9 % [−2,9 % ; +4,9 %] (p = 0,64) ; sans limite +1,4 % [−3,4 % ; +6,4 %] ; fort contre reste +0,7 % [−3,0 % ; +4,5 %] ; moyen −3,4 % (p = 0,055), fort −2,5 % (p = 0,066) contre hors zone + faible ; fort × 2025 −1,2 % [−2,7 % ; +0,3 %] (p = 0,12) ; bascule (placebo) +3,6 % [+1,6 % ; +5,5 %] (p = 0,0003), statut JSON « 853 ventes, 8 communes » ; 193 estimables, 31 significatives (16 / 15), 9,65 attendues ; 16 / 27 / 150 ; quadrants 2 / 9 / 14 / 18.

## « Prime de risque implicite » dans le README : recommandation
Ne pas en faire le nom du résultat. L'étude compare deux zones déjà exposées. Elle ne mesure donc pas une prime de risque, et le titre de l'app pose déjà la vraie question. Employer l'expression une seule fois, comme question de départ et mot-clé utile à un analyste : « La question de départ, une prime de risque implicite sur l'argile, ne peut pas être tranchée ici : on compare deux zones exposées, et on ne trouve pas de différence entre elles. » Ensuite, ajuster `docs/app.md` (« Vocabulaire imposé ») et l'Objectif du CLAUDE.md, qui dit encore « Résultat global (« prime de risque implicite ») ».

## Décret n° 2024-405 : résultat de la vérification
Aucune trace de ce décret sur Légifrance (recherche refusée en 403) ni sur le web. Les sources trouvées décrivent deux autres textes : le décret n° 2024-82 du 5/02/2024 (le vendeur indemnisé doit signaler les travaux non faits, à partir du 1/01/2024) et le décret n° 2024-1101 du 3/12/2024 (expertises, à partir du 1/01/2025). Les états des risques ERRIAL classent le RGA hors obligation IAL. → Ligne 1 du tableau : retirer l'affirmation et garder la variante comme un simple « écart en 2025 ». À confirmer par l'utilisateur sur Légifrance.

## Synthèse
1. Le message central est exact et prudent : « pas de différence détectable entre fort et moyen ; probablement pas plus de 3 % ; l'étude ne dit pas si le marché fait payer le risque ».
2. Deux points bloquent : l'affirmation « réforme 2025 / RGA dans l'état des risques », non vérifiable et probablement fausse, et les libellés « Risque (non) intégré », qui affirment un mécanisme qu'une sinistralité communale ne peut pas montrer.
3. Plusieurs phrases vont plus loin que ce que disent les résultats : « absence de décote », « aucune décote mesurée », « se vendent… moins cher » (p ≈ 0,06), « reflètent surtout des quartiers », placebo « faible puissance ».
4. `docs/method.md`, lié depuis l'app, a pris du retard : ancienne question, simulateur, « primes », 861 contre 853.
5. Ordre proposé : lignes 1-2, puis 3-16 dans une séance textes (un commit, tests de vocabulaire et de chiffres), puis les mineures avec le README.
